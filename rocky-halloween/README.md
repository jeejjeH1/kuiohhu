# 🎃 Night of the Living Rock

سایت تعاملی هالووینی راکی برای مسابقه‌ی **SEISCREATE #03 · #ROCKYHalloween**

کل سایت یک فایل است (`index.html`). نصب و کتابخانه لازم ندارد و صداها هم با کد ساخته می‌شوند، نه فایل صوتی.

## مسیر کاربر
1. **ورود**: لوگو از تیکه‌های جدا سر هم می‌شود و دکمه‌ی **Wake Rocky** ظاهر می‌شود.
2. **مراسم احضار**: صحنه کاملاً تاریک است و موس یا انگشت چراغ‌قوه است. کاربر ۵ شمع (روی سنگ‌هایی به شکل لوگو) را پیدا و روشن می‌کند. با هر شمع یک تیکه از راکی پرواز می‌کند و سر جایش می‌نشیند و یک لایه به موسیقی اضافه می‌شود.
3. **بیدار شدن**: چشم‌ها باز می‌شوند، رعد و برق می‌زند، ترک‌ها از پا تا سر روشن می‌شوند و لوگوی روی سینه می‌درخشد.
4. **Costume Lab**: ۸ لباس (کلاسیک، خون‌آشام، روح، مومیایی، کدوسر، جادوگر، فرانکنشتاین، زامبی)، ۵ رنگ چشم، ۴ نور ترک، ۳ نشان سینه، ۵ وسیله و ۴ صحنه، به‌علاوه‌ی دکمه‌ی تصادفی **Haunt me**.
5. **Rock or Treat**: بازی ۳۰ ثانیه‌ای. کدو +۱۰، آب‌نبات +۵، سنگ قلب طلایی (لوگو) +۲۵ و روح −۱۵ است. آخرش Scare Level می‌گیری.
6. **پوستر**: یک تصویر ۱۰۸۰×۱۳۵۰ با راکیِ خودت، اسمت، لباس، Scare Level و هشتگ. دکمه‌های دانلود، Post on X و کپی متن پست هم دارد.

| زمزمه | بعد از بیدار شدن راکی، ۳۰ ثانیه هیچ کاری نکن |

## آپلود رایگان روی Vercel
1. وارد vercel.com شو، بعد **Add New → Project** و همین مخزن را Import کن.
2. **Root Directory** را روی `rocky-halloween` بگذار و Deploy کن.
3. آدرسی که گرفتی را در `index.html` جلوی `SHARE_URL` بگذار تا دکمه‌ی Post on X لینک سایت را هم داخل متن بگذارد. اگر آدرس با `vercel.app` تمام شود، این کار خودکار انجام می‌شود.

راه سریع‌تر: پوشه‌ی `rocky-halloween` را بکش و روی app.netlify.com/drop رها کن.

## ضبط ویدیو برای X (۲۰ تا ۳۰ ثانیه)
- دکمه‌ی **Fullscreen** گوشه‌ی صحنه را بزن تا فقط صحنه دیده شود.
- **Replay ritual** مراسم را از اول اجرا می‌کند، پس می‌توانی چند بار ضبط کنی.
- ترتیب پیشنهادی: تاریکی و چراغ‌قوه، روشن کردن شمع‌ها، رعد و بیدار شدن، عوض کردن سریع چند لباس، چند ثانیه از بازی، و آخرش پوستر.
- صدا را روشن بگذار، چون نصف ترسناکی‌اش از صداست.
