# 🔥 Molten Rocky: ویدیوی سه‌بعدی برای #ROCKYHalloween

یک ویدیوی سه‌بعدی **عمودی ۱۰۸۰×۱۹۲۰**، **۱۵ ثانیه**، **۳۰ فریم بر ثانیه**. ابتدا و انتهایش یکی است تا در X پشت سر هم تکرار شود. همه‌اش با کد ساخته شده: مدل، نور، انیمیشن و صدا.

| فایل | چیست |
|---|---|
| `molten_rocky_9x16.mp4` | **ویدیوی نهایی** با صدا، آماده‌ی آپلود در X |
| `molten_rocky_poster.png` | پوستر ۱۰۸۰×۱۳۵۰ برای پست یا رشته‌توییت |
| `index.html` | صحنه‌ی سه‌بعدی (Three.js). هر فریم تابعی از زمان است |
| `render.js` | رندر فریم‌به‌فریم با Chromium و ساخت MP4 با ffmpeg |
| `audio.py` | موسیقی و افکت‌های صوتی، ساخته‌شده با کد |
| `vendor/` | Three.js r170 (مجوز MIT) |

## استوری‌بورد
| زمان | اتفاق |
|---|---|
| ۰ تا ۱.۵ ثانیه | تاریکی و مه. چشم‌ها با یک چشمک روشن می‌شوند. |
| ۱ تا ۳.۵ | متن *"He slept in the quarry for a thousand years."* |
| ۱.۵ تا ۴ | ترک‌ها از پا تا سر روشن می‌شوند، با لبه‌ی سفید داغ و صدای غرش و سنگ. |
| ۳.۷ تا ۶.۵ | متن *"Tonight… he wakes up."* |
| ۰ تا ۱۵ | دوربین یک دور کامل ۳۶۰ درجه دور راکی می‌چرخد، از زاویه‌ی پایین. |
| ۸.۵ | ⚡ رعد و برق |
| ۱۲.۶ | تیتر **NIGHT OF THE LIVING ROCK** همراه لوگو و هشتگ |
| ۱۳ تا ۱۵ | ترک‌ها سرد می‌شوند و چشم‌ها خاموش، و ویدیو به اول برمی‌گردد. |

## چطور ساخته شده
- **راکی** از ۱۹ تکه سنگ چندوجهی ساخته شده (Convex Hull با گوشه‌های بریده و برآمدگی‌های تصادفی). هر وجه رنگ خودش را دارد.
- **ترک‌های گدازه**: هر لبه‌ی هر وجه یک میله‌ی نورانی است، با چند صد نمونه (InstancedMesh). روشن شدنشان به ارتفاع بستگی دارد، پس آتش از پا به سر بالا می‌رود.
- **لوگو** روی سینه و روی سنگ قبرهاست (شکل لوگو Extrude شده).
- کدوهای حکاکی‌شده با نور شمع، ۳۲۰ جرقه که از ترک‌ها بلند می‌شوند، مه، خفاش‌ها، ماه، کوه‌های چندوجهی و درخت‌های خشک.
- پس‌پردازش: Bloom، ویگنت، نویز فیلم و فلش رعد.

## ساخت دوباره
```bash
python3 audio.py                 # -> out/audio.wav
node render.js video 4           # -> out/video_noaudio.mp4 (۴ پردازش موازی)
node render.js preview 2.6 8.52  # -> preview/*.png برای دیدن فریم‌ها
node render.js poster            # -> molten_rocky_poster.png
ffmpeg -i out/video_noaudio.mp4 -i out/audio.wav -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart molten_rocky_9x16.mp4
```

برای دیدن زنده‌ی صحنه در مرورگر، داخل همین پوشه `python3 -m http.server` را اجرا کن و `http://localhost:8000` را باز کن. مرورگرها ماژول‌ها را از `file://` بار نمی‌کنند.
