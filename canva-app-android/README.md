# طرح‌ساز — نسخه‌ی اندروید (APK)

فایل نصبی: **`dist/tarhsaz.apk`** (اندروید ۷ به بالا، حدود ۲٫۳ مگابایت)

## نصب
1. فایل `tarhsaz.apk` را روی گوشی بریزید و بازش کنید.
2. اگر اندروید پرسید، اجازه‌ی «نصب از منابع ناشناس» را برای همان برنامه (فایل‌منیجر یا مرورگر) بدهید.
3. اپ «طرح‌ساز» را از منوی برنامه‌ها اجرا کنید.

## ویژگی‌های نسخه‌ی اندروید
- همه‌ی قابلیت‌های نسخه‌ی وب، به‌صورت کاملاً **آفلاین**؛ هر ۱۸ فونت داخل خود اپ هستند.
- دانلود خروجی‌ها (PNG، JPG، PDF و فایل پشتیبان پروژه) در پوشه‌ی `Download/Tarhsaz`.
- اشتراک‌گذاری مستقیم در تلگرام، واتس‌اپ، اینستاگرام و اپ‌های دیگر.
- انتخاب عکس از گالری، و کار کردن دکمه‌ی «بازگشت» گوشی.
- طرح‌ها روی خود گوشی ذخیره می‌شوند.

## ساخت دوباره
```bash
sudo apt-get install aapt dalvik-exchange zipalign apksigner   # یک بار
./build.sh
```
اسکریپت بدون نیاز به Gradle یا Android Studio، پوشه‌ی `../canva-app` را همراه فونت‌ها در یک WebView بومی بسته‌بندی و امضا می‌کند.

> ⚠️ کلید امضا (`keystore/tarhsaz.jks`) عمداً داخل گیت نیست. برای نصب نسخه‌های بعدی روی همین نصب قبلی، و بدون پاک شدن طرح‌ها، باید با **همان کلید** امضا شوند. فایل کلید را جای امنی نگه دارید و موقع ساخت در `keystore/` بگذارید.
