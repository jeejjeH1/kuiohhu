# ROCKY Halloween: "MAGNITUDE 10.31" (work in progress)

A 30-second, 4:5 Halloween short for #ROCKYHalloween.
On Halloween night, a seismic station picks up strange tremors. They turn out to be Rocky's footsteps. After all the fear, he only came for candy.

## Assets so far
- `assets/fonts/`: Creepster, Special Elite, Oswald (Google Fonts, OFL/Apache licensed)
- `assets/voice_raw.wav`: "Trick, or treat." synthesized with Piper (en_US ryan high). It will be pitched down for Rocky's voice.

## Storyboard
| Time | Scene |
|---|---|
| 0–3s | Dark station, desk lamp, flat seismograph line, pumpkin candy bowl, sign `SEISMIC STATION — OCT 31`, clock 23:58 |
| 3–6s | Soft thump: candies jump, small spike |
| 6–9.5s | Louder thumps: lamp flickers, dust falls, needle goes wild |
| 9.5–12s | Red alarm `MAGNITUDE 10.31 DETECTED`, lamp dies |
| 12–14s | Paper spits out (close-up: chaotic lines only), alarm dies |
| 14–15s | Black, total silence |
| 15–20s | Rocky: white eyes, then chest logo, then rock seams glow orange like a jack-o'-lantern (low angle, hands on hips) |
| 20–24s | Tilt down to a tiny pumpkin bucket: "Trick… or treat." Display shows `MAGNITUDE 0.01` in green |
| 24–27s | Pull back from the paper: the stacked tremor rows form the Seismic logo |
| 27–30s | End card: `MAGNITUDE 10.31` / `#ROCKYHalloween` |
