# طرح‌ساز — اپ طراحی گرافیک موبایل (شبیه Canva)

اپ موبایل نصب‌شدنی (PWA) با رابط کاملاً فارسی و راست‌به‌چپ، که بدون سرور و بدون مرحله‌ی build اجرا می‌شود و آفلاین هم کار می‌کند.

## اجرا

```bash
cd canva-app
python3 -m http.server 8080      # یا هر وب‌سرور استاتیک دیگر
```

سپس `http://localhost:8080` را در موبایل یا مرورگر باز کنید. در موبایل از منوی مرورگر گزینه‌ی **«افزودن به صفحه اصلی / Install app»** را بزنید تا مثل یک اپ مستقل نصب شود.
برای نصب PWA روی گوشی باید اپ با HTTPS سرو شود (مثلاً GitHub Pages، Netlify یا Vercel).

### نسخه‌ی اندروید (APK)
فایل نصبی آماده در `../canva-app-android/dist/tarhsaz.apk` است. راهنمای نصب و ساخت دوباره در [`canva-app-android/README.md`](../canva-app-android/README.md) آمده است.

## قابلیت‌ها

**صفحه‌ی اصلی**
- ساخت طرح با ۱۲ اندازه‌ی آماده (پست و استوری اینستاگرام، پوستر، ارائه، تامبنیل یوتیوب، لوگو، کارت ویزیت، کاور، بنر، A4، والپیپر) یا اندازه‌ی دلخواه
- گالری ۱۴ قالب آماده‌ی فارسی با جستجو و دسته‌بندی (شامل قالب ارائه‌ی چندصفحه‌ای)
- پروژه‌های من: باز کردن، تغییر نام، کپی، حذف، پشتیبان‌گیری و وارد کردن فایل پروژه (`.tarh.json`)
- تم روشن و تاریک

**ویرایشگر**
- جابه‌جایی، تغییر اندازه و چرخاندن با دستگیره‌ها، و با دو انگشت (pinch) برای بزرگ‌کردن یا چرخاندن عنصر انتخاب‌شده
- زوم و جابه‌جایی صفحه با دو انگشت، و برگشت به حالت اولیه با دو ضربه
- خطوط راهنما و چسبیدن خودکار به وسط و لبه‌های صفحه و عناصر دیگر، و چسبیدن زاویه به مضرب‌های ۴۵ درجه
- واگرد/ازنو (Undo/Redo) و ذخیره‌ی خودکار در IndexedDB
- **متن:** ۱۸ فونت فارسی و لاتین، اندازه، رنگ ساده یا گرادیان، ضخیم، کج، زیرخط، حروف بزرگ، تراز، فاصله‌ی حروف و خطوط، سایه، حاشیه دور حروف، کادر هایلایت، و افکت‌های آماده (نئون، توخالی، سایه‌ی بلند و…)
- **عناصر:** ۱۸ شکل (مستطیل گرد، دایره، ستاره، قلب، فلش، حباب گفتگو، خط، خط‌چین و…)، ۳۲ آیکون و گرافیک، و ۹۶ استیکر
- **عکس:** آپلود از گالری یا دوربین، ۱۲ فیلتر آماده، تنظیم روشنایی، کنتراست، اشباع، Hue، محو و…، برش و بزرگنمایی، نسبت‌های آماده، قاب‌های شکلی (دایره، قلب، ستاره و…)، حاشیه، سایه، جایگزینی، و تبدیل به پس‌زمینه
- **پس‌زمینه:** رنگ، گرادیان خطی و دایره‌ای، عکس، یا شفاف
- **قلم:** نقاشی آزاد با رنگ و ضخامت دلخواه
- **رنگ‌ها:** پالت پیش‌فرض، رنگ‌های اخیر، رنگ‌های به‌کاررفته در طرح، **کیت برند**، انتخاب رنگ دلخواه و قطره‌چکان (در مرورگرهایی که پشتیبانی می‌کنند)
- لایه‌ها (نمایش و پنهان، قفل، ترتیب)، تراز با صفحه، ابعاد و موقعیت دقیق، قرینه، شفافیت، تکثیر و حذف
- چند صفحه‌ای: افزودن، تکثیر، حذف و جابه‌جایی صفحه‌ها
- **تغییر اندازه‌ی جادویی:** تبدیل طرح به اندازه‌ی دیگر، روی همین طرح یا به‌صورت یک نسخه‌ی جدید
- **خروجی:** PNG (با امکان پس‌زمینه‌ی شفاف)، JPG و PDF چندصفحه‌ای، در کیفیت‌های ۰٫۵ تا ۳ برابر، با دانلود یا اشتراک‌گذاری مستقیم در اپ‌های دیگر (Web Share)
- میانبرهای صفحه‌کلید در دسکتاپ: `Ctrl+Z/Y`، `Ctrl+D`، `Delete` و کلیدهای جهت‌دار

## ساختار کد

| فایل | کاربرد |
|---|---|
| `js/model.js` | مدل داده، اندازه‌ها، فونت‌ها، شکل‌ها، آیکون‌ها، استیکرها و پالت‌ها |
| `js/renderer.js` | رسم صفحه روی Canvas؛ برای ویرایشگر، پیش‌نمایش و خروجی مشترک است |
| `js/editor.js` | ویرایشگر: ژست‌های لمسی، نوار ابزار و پنل‌ها |
| `js/home.js` | صفحه‌ی اصلی، قالب‌ها و پروژه‌ها |
| `js/templates.js` | تعریف قالب‌های آماده |
| `js/export.js` | خروجی PNG، JPG و PDF (سازنده‌ی PDF داخلی و بدون کتابخانه) |
| `js/store.js` | ذخیره‌سازی در IndexedDB |
| `sw.js` | Service Worker برای اجرای آفلاین |

## محدودیت‌ها نسبت به Canva
قابلیت‌هایی که به سرور یا هوش مصنوعی نیاز دارند، مثل حذف پس‌زمینه، کتابخانه‌ی عکس آنلاین، همکاری هم‌زمان، ویدیو و انیمیشن، در این نسخه نیستند. انتخاب چند عنصر هم‌زمان و گروه‌بندی هم هنوز پیاده نشده است.
